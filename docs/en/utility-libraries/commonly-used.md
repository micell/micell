# Utility Libraries

Here are some commonly used utility libraries.

> Reach for built-in APIs first: `structuredClone`, `Intl.*`, `crypto.randomUUID`, `Promise.withResolvers`, and the newer `Array`/`Object` methods already cover many small helpers.

## General

* [es-toolkit](https://github.com/toss/es-toolkit): A modern lodash replacement, tree-shakable and TypeScript-first.
* [remeda](https://github.com/remeda/remeda): TypeScript-first, data-first utility functions.
* [Micell](https://github.com/micell/micell): A collection of functions for front-end development.
* [immer](https://github.com/immerjs/immer): Immutable updates through structural sharing.
* [immutable](https://github.com/immutable-js/immutable-js): Persistent immutable data structures.

## Date & Time

* [dayjs](https://github.com/iamkun/dayjs): 2 kB immutable date library with a Moment.js-compatible API.
* [@internationalized/date](https://github.com/adobe/react-spectrum): Date and time utilities for internationalized interfaces.
* [pretty-ms](https://github.com/sindresorhus/pretty-ms): Convert milliseconds to a human-readable string.
* [parse-ms](https://github.com/sindresorhus/parse-ms): Parse a human-readable duration back into milliseconds.

## Numbers

* [pretty-bytes](https://github.com/sindresorhus/pretty-bytes): Convert bytes to a human-readable string.
* [filesize](https://github.com/avoidwork/filesize.js): File size formatting with IEC and SI support.

## Strings & Encoding

* [js-base64](https://github.com/dankogai/js-base64): Base64 and Base64URL encoding for strings and binary data.

## URL & Query

* [qs](https://github.com/ljharb/qs): Query string parsing and serialization with nested objects.
* [query-string](https://github.com/sindresorhus/query-string): Parse and stringify URL query strings.

## Validation

* [zod](https://github.com/colinhacks/zod): TypeScript-first schema validation with static type inference.

## Unique IDs

* [nanoid](https://github.com/ai/nanoid): Small, URL-safe ID generator.
* [uuid](https://github.com/uuidjs/uuid): UUID generation, including v7.

## Color

* [colord](https://github.com/omgovich/colord): Tiny color parser and manipulator with plugins for lab/lch and mixing.
